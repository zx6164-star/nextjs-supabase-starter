## 개발 원칙
1. **RLS 없는 테이블 배포 금지** — 모든 신규 테이블은 RLS 정책과 함께 커밋
2. **서버 컴포넌트 우선** — 상호작용이 필요한 최소 범위만 클라이언트 컴포넌트로 분리
3. **Phase 1 완료 후 Phase 2 착수** — 핵심 CRUD가 안정화되기 전 확장 기능 추가 금지
