# PRD: TaskFlow — Supabase 기반 할 일 관리 앱

**버전:** 1.0
**작성일:** 2026-07-31
**상태:** 초안

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| **프로젝트명** | TaskFlow |
| **목적** | 로그인한 사용자가 자신만의 할 일 목록을 만들고 관리하는 개인용 태스크 관리 앱 |
| **타깃 사용자** | 간단한 할 일 관리 도구가 필요한 1인 사용자 |
| **왜 Supabase인가** | 별도 백엔드 서버 없이 인증(Auth)과 데이터베이스(Postgres)를 동시에 제공, RLS로 사용자별 데이터 격리를 DB 레벨에서 보장 |

### 핵심 가치
- **간단함**: 회원가입 후 바로 할 일을 추가/완료/삭제할 수 있는 최소한의 흐름
- **데이터 격리**: RLS 정책으로 각 사용자는 본인의 할 일만 조회·수정 가능
- **빠른 반응**: 서버 컴포넌트 기반으로 초기 로딩 최소화

## 3. 핵심 기능

### 3.1 인증 (스캐폴딩 완료)
- 이메일/비밀번호 회원가입, 로그인, 로그아웃
- 비밀번호 재설정 (forgot-password → update-password)
- 미인증 사용자는 `/protected` 이하 접근 시 로그인 페이지로 리다이렉트

### 3.2 할 일 관리 (신규 개발 대상)
- 할 일 추가 (제목, 선택적 설명)
- 할 일 목록 조회 (본인 데이터만, 최신순)
- 완료/미완료 토글
- 할 일 삭제
- 완료된 항목과 미완료 항목 구분 표시

### 3.3 확장 기능 (Phase 2)
- 우선순위 설정 (낮음/보통/높음)
- 마감일 지정 및 임박 항목 강조
- 카테고리/태그 분류

## 4. 사용자 스토리

| 역할 | 스토리 |
|------|--------|
| 신규 사용자 | 이메일로 회원가입하고 확인 메일을 받아 계정을 활성화하고 싶다 |
| 로그인 사용자 | 로그인 후 내 할 일 목록만 보고 싶다 (다른 사람 데이터는 절대 보이면 안 된다) |
| 로그인 사용자 | 할 일을 빠르게 입력하고 Enter만으로 추가하고 싶다 |
| 로그인 사용자 | 완료한 항목을 체크하면 목록에서 흐리게 표시되어 구분되길 원한다 |
| 로그인 사용자 | 더 이상 필요 없는 할 일을 삭제하고 싶다 |
| 로그인 사용자 | 비밀번호를 잊어버렸을 때 이메일로 재설정하고 싶다 |

## 5. 데이터 모델 (Supabase)

### tasks 테이블
| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | uuid | 기본키 |
| `user_id` | uuid | `auth.users` 참조, 소유자 |
| `title` | text | 할 일 제목 |
| `description` | text | 상세 설명 (선택) |
| `is_completed` | boolean | 완료 여부, 기본 false |
| `priority` | text | Phase 2: 낮음/보통/높음 |
| `due_date` | date | Phase 2: 마감일 |
| `created_at` | timestamptz | 생성 시각 |

> RLS: 모든 CRUD 작업은 `auth.uid() = user_id` 조건을 만족해야 함

## 6. MVP 범위

### ✅ MVP에 포함
- 회원가입/로그인/로그아웃 (스캐폴딩 완료)
- `tasks` 테이블 생성 + RLS 정책
- 할 일 추가/조회/완료토글/삭제
- 반응형 기본 레이아웃

### ❌ MVP에서 제외 (Phase 2 이후)
- 우선순위, 마감일, 카테고리
- 할 일 검색/필터
- 다크모드 토글
- 협업(공유 리스트) 기능
